# Onion Score illustrations

Six locally authored SVG illustrations, using the established purple Onion Head
character as visual reference. All share a 96 × 104 viewBox and scale without
external assets, scripts or fonts. Files: `index-fresh.svg`, `index-spotted.svg`,
`index-bruised.svg`, `index-spoiled.svg`, `index-rotten.svg`, `index-unrated.svg`.

States differ through leaf posture, facial expression and skin markings as well
as color. The gray neutral state means no index is available. The illustrations
describe the documented product-problem score: higher is worse. Fresh is [0,20),
Spotted [20,40), Bruised [40,60), Spoiled [60,80), Rotten [80,100]. Pending research
is gray, not Fresh. `product-issues-v1` replaces the historical vote-share and
confidence definitions. The UI provides the formula, source requirements and limits.

The image-generation service failed with an invalid-credential error during this
task. No generated sprite was used; the shipped icons were drawn as SVG paths.
