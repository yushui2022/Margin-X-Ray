# Creator directory, reports and price archive

The old directory clipped the sort selection on phone screens. The static edition showed a coverage-vote column with no voting controls, and incoming links to a creator’s source or quality tab scrolled the creator’s identity out of view. Archive cards put creator, variant and price in different vertical positions, making prices harder to scan across records.

The revised directory links the featured Sony retail check to its documented creator and shows controls available in the current edition. The archive aligns recorded prices and preserves each currency and source link. A compact creator header keeps the portrait, retail index and selected evidence section together on direct entry. The secondary navigation fits a 375 px screen in one row.

Chrome checks covered 320, 375, 768, 1024 and 1440 px for the directory, archive, creator report, profile sources, quality tab and a standalone product record. None overflowed horizontally. Both source and quality deep links opened at the top. At each width the checks exercised the priced-products filter, research filter, reset, sorting, pagination, handle search, tab navigation, restoration on Back, currency filter, empty search and original source links. The rendered profile kept Kylie Jenner’s 20.4/100 retail price index distinct from her evidence and product-issue scores.

Seven isolated directory and feedback tests passed. The shared-vote tests start a loopback server backed by a temporary database and cover retries, switching, withdrawal, persistence after restart and version isolation. No public votes were written.
