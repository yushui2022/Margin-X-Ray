# Creator directory and price archive

On the 375px English baseline, the directory showed a Sony promotion above the search results. The first creator started at y=519. The archive led with a single recorded listing, and the first product name in its list started at y=467.

The directory now pairs each creator with a documented product where available, and links to their product records and evidence. The ranking preview uses a sourced TikTok Shop account. The default directory rows distinguish a checked price index from insufficient matches. Choosing an evidence sort shows the separate coverage score.

The archive opens with two-shop comparisons. Each card shows its market, price basis and observation date. The Kylie Matte Lip Kit check records $35 item prices at both stores in Oregon, with standard delivery making the difference $8.95. The single-listing records have a separate section. Its result count is a keyboard-accessible shortcut to the section.

## Verification

- Reviewed both languages at 320, 375, 768, 1024 and 1440px. None of the tested routes overflowed horizontally. At 375px in English the first directory row started at y=444. The first comparison showed both shop prices and its source link within the first viewport.
- Checked the directory's 500 profiles, 12 profiles with priced products, pagination, filtering, evidence sorting, exact handle search, report links and Back restoration. Tested vote switching, withdrawal, retry and persistence against an isolated local database.
- Checked 5 paired comparisons and 21 historical item prices. EUR showed only two listings and GBP only the UK Sony pair. The Haus Labs check showed equal item prices and unconfirmed delivery. An expired-date test suppressed savings headlines. Switching currencies, following source records, moving to either section and returning to a filtered view all worked.
- The source type check, build and 260 automated tests passed. Screenshots in this directory show actual desktop and mobile renders. English before and after captures are directly comparable. The additional Chinese captures verify the localized UI.
