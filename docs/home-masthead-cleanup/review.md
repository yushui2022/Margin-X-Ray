# Homepage masthead

The edition line above the purpose headline repeated the index name and displayed the creator count and date before the search task. Removing that line lifted the headline, search field and first archive row by 23px at 375px and 27px at 1440px. The headline now follows the Onion Head navigation directly.

Chromium checks covered widths of 320, 375, 768, 1024 and 1440px. Each displayed the purpose headline and 15 collapsed creator rows with no horizontal overflow. Entering a saved creator's handle opened their report. Enter and Space expanded and collapsed the first row, which showed the $10.11 price gap. The full ranking link opened its destination.
