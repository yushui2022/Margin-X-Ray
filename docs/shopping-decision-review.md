# Buying decision report review

The shopper needs to know whether to favor the original offer, seek a closer comparison or use another shop. The same recorded price gap can have a different meaning for a measured commodity, a documented collectible edition and a verified identical SKU. The report keeps the observed gap visible alongside the evidence used for its buying call.

## Interaction evidence

- The first decision layout put the action, price band and confidence in the hero. The second pass added a score pointer, the applicable item allowance and the four-step explanation. The methodology exposes the starting allowances and point thresholds.
- Browser fixtures exercised an exact alternative, two similar shops contributing a median, an original below the reference, equal prices, a maximum score, an incompatible pack size, a missing peer, a multi-product profile and a frozen v1 report. The below-reference example retained its raw discount and scored zero. The pack mismatch explained the differing quantities and remained unrated.
- Expanding the scoring method, per-item seller evidence and follow-up search note issued zero new shopping jobs. A five-post profile exposed three independent item receipts and all five source links. An interrupted historical review displayed the server message and allowed another click. Success opened the new result and a link returned to the original. Only explicit review clicks sent a reassessment POST.
- The published v1 and a new v2 video check supplied the before and after evidence. In the new run one additional seller was checked and one eligible peer remained. $59.99 against $49.95 yielded an observed gap of 20.1%. The 15% allowance placed the ceiling at $57.44. The original was 4.4% above that ceiling and scored 9/100, with low confidence and the buying call “Wait for a closer match.”
- Chromium viewport emulation covered 320, 375, 768, 1024 and 1440 CSS pixels. The review includes saved evidence and isolated response states. Observations are limited to these browsers and report inputs.
